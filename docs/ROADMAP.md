# Roadmap

## v1: Launch (this build)
Home, About, Events + detail, Team + archive, Gallery + albums, Wall of Fame, Blog + posts, Contact, 404 game. Hidden admin panel via the terminal ritual. Founder XP, terminal, easter eggs. Signature animations with motion tiers.

Explicitly **not** in v1: sponsors page, event registration, recruitment, member accounts.

## v1.1: Partners (after launch, when the sponsorship team is ready)
- `/sponsors` page: audience composition, past partners wall, tiers comparison table, deck download (tracked), partnership inquiry form (reuses the contact action with extra fields).
- `sponsors` table + admin screen (logo SVG upload, tier, years, link).
- "Backed by" logo wall on Home and event detail pages.
- Per-event sponsors.

## v1.2: Recruitment
- `/join`: open/closed status driven by dates in settings, open roles table, process timeline, application form (stored in the DB, reviewed in admin), reminder signup when closed.
- Admin: applications inbox with status pipeline (new → shortlisted → interview → selected/rejected) and CSV export.

## v1.3: Native event registration
- Registration forms per event (custom fields), capacity, waitlist, confirmation emails with QR, check-in screen for volunteers on mobile.
- Keeps external links (Devfolio/Unstop) as an option per event.

## v2: Community
- Optional member accounts (Google sign-in for students). XP syncs to the server.
- Public leaderboard (opt-in, display name only).
- Badges earned at real events (scan a QR at Singularity → badge).
- Projects / ventures showcase with stage pills.
- Mentors directory.
- Newsletter (only if someone owns sending it).

## Ideas parking lot
- Interactive 3D campus map for events.
- Live hackathon dashboard (timer, announcements, team submissions) during Singularity.
- "Pitch roulette" game: random startup prompt, 60s timer, share card.
- Hindi/Marathi translations.
